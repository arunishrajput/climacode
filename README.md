# Futuristic Climate Window

## Overview
This interactive website features a circular window displaying a soothing climate animation. Users can customize the scene with various elements, such as weather effects, fog, and airplanes.

## Features
- Interactive circular window
- Customizable animations (weather, fog, airplanes, etc.)
- Soothing visual experience

## Get Started
1. Visit the website: [https://climwheel.vercel.app/](https://climwheel.vercel.app/)
2. Use the controls to tweak animations to your liking.
3. Enjoy the immersive climate experience!
